# Workshop Inside REI

Aplicação Full-stack desenvolvida para venda de ingressos e gestão de eventos.

## Tecnologias Utilizadas
* Node.js
* MongoDB
* HTML, CSS e JavaScript
* Integração com API do Mercado Pago

## Funcionalidades
* Venda de ingressos online com interface responsiva
* Aprovação automática de pagamentos via webhooks do Mercado Pago
* Geração de ingressos digitais sequenciais
* Estruturação avançada de dados de usuários no banco de dados
* Painel administrativo para controle de check-in
